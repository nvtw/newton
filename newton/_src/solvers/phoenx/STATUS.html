Data-layout result: patch traversal is faster

Compact patch rows now keep both forward tree responses and solved body deltas in registers, exchanging parent values with subgroup shuffles. This removes two global-memory recurrences without changing the ABA or hard-contact equations.

  • Randomized 24-step production G1 graph trajectories are bitwise identical to the old global-memory paths.
  • Randomized rows match exactly on generic 8-, 16-, and 32-lane branched trees.

Correctness issue found and fixed

A pre-existing warp advance silently skipped joints when one tree depth contained more than 32 joints. A 62-child test differed from serial ABA by as much as 0.604 rad/s. Such trees now select the exact serial advance; the extended regression is bitwise exact. A future multi-wave/grid-stride design can restore parallel speed without weakening this guard.

Wall-to-policy state

PhoenX throughput is competitive, but it does not yet match nanoG1 wall-to-policy robustly. The retained seed-42 hard-contact policy passes at 141.56M samples / 84.18 s; nanoG1 reports 75.1M / 58.9 s for one seed. Seed 43 variability shows sample efficiency remains the larger gap.

The current redesign attacks throughput without changing the hard Hertz model. The latest short full-PPO bracket reaches about 1.90M samples/s, making 131M samples roughly 69 s under the same benchmark conditions; a fresh long bracket will refine this after the commit.

Retained learner-layout result

Sparse FP32 MinGRU checkpoints plus four-step register recomputation preserve the recurrence equations. Nsight measures forward at 53.2 → 43.9 µs (-17%); backward is neutral at 110.9 → 111.2 µs. Randomized reset-boundary outputs and gradients are bitwise exact, graph replay is deterministic, and the final full G1 run reaches 1.887M samples/s versus the 1.869M/s pre-change trace.

Current data-layout focus

The BF16 MinGRU activation layout is qualified: projection storage falls 151.0 → 75.5 MB, isolated forward/backward improves 0.776 → 0.730 ms, and an A/B/B/A bracket averages 1.887M → 1.902M samples/s (+0.8%). FP32 recurrence/accumulation, gradient checks, and deterministic replay pass. Seed 42 passed the full 131.072M-sample gate with zero falls and 0.918 battery performance in 70.64 s training / 75.09 s including save, reload, and gate. Depth-local physics repacks were neutral or worse. A follow-up that fused next-layer BF16 shadows improved the isolated recurrent graph 0.730 → 0.713 ms but reduced full A/B/B/A throughput 1.940M → 1.927M/s, so it was removed.
