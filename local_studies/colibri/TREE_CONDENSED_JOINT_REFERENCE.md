## Derivation without alignment assumptions

For each oriented tree edge, use its actual saved reformed child and parent row blocks A and B. A local rectangular QR solves A v_child + B v_parent=0 and exposes the child's free velocity directions. Propagating those relations from the forest roots constructs N, spanning the actual hard-tree velocity nullspace. It does not assume authored parent/child axes or anchors are exactly aligned.

With physical mass M=W^-1, form M_reduced=N^T M N. Its Cholesky gives an inverse square root S; T=N S is a physical mass-orthonormal body map. Project the initial velocity into the hard-tree subspace using T T^T M.

Then factor [J_remaining T,sqrt(R)] after removing only exact certified dual dependencies. The existing drive compliances R remain unchanged. Its orthogonal complement gives G=T Z_body, hence physical contact mobility P=G G^T. The baseline loop/drive correction uses the same existing drive targets and accumulated impulses.

Finally recover all tree reaction impulses by reverse tree traversal using each local child QR. This independently verifies that the final velocity change is generated by the original reformed J^T impulses, rather than merely satisfying its velocity equations.

Existing reduced.py uses authored joint transforms/axes for configuration-based kinematics. Its traversal/factor infrastructure may be reusable, but directly substituting its usual motion subspaces would assume a joint-compatible pose. This diagnostic instead derives each local map from the actual maximal-coordinate rows, preserving the captured geometry.

## Limits

The studied solve is frozen unbiased relaxation. Live biased recovery requires an affine tree particular solution, not silently imposing zero tree target velocity. Finite drive bounds, topology changes, and generic joint types require explicit handling. Global contact convergence is still unfinished. No canonical source changes, live correction or production performance claim is made.
