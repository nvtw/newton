## Scope and ownership

Eligible complete islands: at most two dynamic bodies and nine contact points, static external endpoints, no incident joints/reduced ownership/PD until supported explicitly. This is computational strategy selection; no contact is dropped. Initially replace only existing unbiased relaxation, keep speculative rows fixed and preserve original biased8x8 work. Candidate trials use the same pre-relax physical state and accumulated impulses. On acceptance scatter J-transpose delta once and suppress all replaced native rows. On failure run existing native relaxation unchanged. Never apply both. Warm contact modes are hints mapped by stable contact identity and independently rechecked.

## Proposed GPU representation

Retain F=J M^-1/2 (up to27x12) from actual physical body blocks, plus27impulses. Solve augmented response equations y-F^T lambda=0 and the original normal complementarity/tangent disk map. Newton system is nonsymmetric; SPD cone-QP is the wrong law. A39x39 pivoted QR buffer plus original matrix is24.3KB FP64; F and work vectors bring typical shared storage near30KB before kernel-specific scratch. One cooperative block per complete island is plausible. An explicit sliding multiplier formulation can reach48variables for9slidingpoints and needs more memory. Keep genuine body response modes; only certified machine-null impulse directions can be treated as redundant.

A39x39 QR is roughly1.6e5arithmetic operations before pivot/reduction overhead. Twelve Newton steps already approach2million operations per island/update; a tail queue adds more. No FPS prediction without replay and actual GPU profiling. Use bounded work (12natural-map steps, eight neighboring faces each at most8steps,16backtracks/step), not exhaustive enumeration. Every result must satisfy original1e-8 Coulomb checks, friction cone, all rows, nonpositive unbiased contact work, and physical reaction/midpoint work budgets.

## Case 362_5: certified support-line geometry and gauge obstruction

The earlier nine-gauge interpretation is superseded. This frozen case has two ground support points and five inter-body contacts. Exact rational reconstruction of the shared world pivots, original directions, and cross products gives dynamic contact Jacobian rank 11, hence ten pure-dual impulse directions. Both bodies can rotate together about the line joining the two ground points without contact-point relative motion. This null twist has exactly zero symbolic Jacobian product. Reconstructing physical primitives at 70 digits gives the last response-factor singular value 1.32e-71; the 2.16e-18 value obtained by high-precision SVD of the already rounded FP64 matrix is a cross-product rounding artifact. The explicit reconstructed Jacobian changes at most 1.11e-16; no singular-value threshold deletes a physical mode.

Fixed-response feasibility nevertheless fails for a structural reason. All normal velocities are within the unchanged 1e-8 criterion, but point 0 has resolved tangential speed 1.623e-5 m/s. Restricting its exact sliding equations to the ten certified gauge directions gives equality rank one and augmented rank two. A normalized left-null certificate has an incompatible right-hand side of 0.489530244 N·s. Impulse redistribution can change that ground-point impulse only along one direction and cannot align it with the fixed sliding velocity. Therefore a velocity/mode change is required; pure-dual redistribution cannot make this candidate satisfy the original Coulomb law. SLSQP independently stops at singular equalities without changing the candidate; this optimizer failure alone is not the infeasibility proof.

### Bounded objective-tie seed selection

`certified_normal_seed.py` preserves the original enumerated active-set implementation as a control. The local candidate keeps its feasibility checks unchanged, then considers objectives tied only when their evaluation intervals overlap. The objective error radius is `gamma_(3n+3) * (0.5*abs(x)^T*abs(A)*abs(x) + abs(b)^T*abs(x))`, with `gamma_k=k*eps/(1-k*eps)`. Tied candidates must additionally match the unsquared normal impulse response within a conservative FP64 product/subtraction bound, `8*gamma_(3n+3)*max(abs(F_n.T)@(abs(x)+abs(x_best)))`. Selection minimizes impulse norm among these enumerated candidates, with deterministic mask ordering. This is not a claim to minimize norm over the full continuous degenerate solution set. No physical singular direction is dropped.

With the same eight seed sweeps and unchanged nonlinear budgets, both the prior-failed and exact-cross versions of 362_5 pass at approximately 1.96e-10 residual, 17 solves and 99 augmented residual evaluations. Their final seeds differ by 2.72e-5 N·s, versus the previous 4.68 N·s jump. Cases 244_0 and 245_1 retain acceptance; 245_1 now needs 17 solves/184 evaluations. Case 263_2 is unchanged and rejected at 1.7965e-4; 300_2 improves to 0.0307563 but remains rejected. All accepted physical momentum/work audits pass below 3.56e-15, with negative energy change.

The response-equivalence check applies to each tied normal subproblem, not the entire seed trajectory: different normal impulse distribution changes subsequent tangent disk radii, so the complete numerical seeds can have different velocities. These seeds never become simulated states; only a final unchanged original-law KKT acceptance allows a reference solution. Maximum response differences within eligible ties range up to 1.44e-13 in these six controls. No broad replay or production promotion.
