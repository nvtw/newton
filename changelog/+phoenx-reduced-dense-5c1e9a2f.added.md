Add `reduced_backend="dense"` to `SolverPhoenX` reduced articulations, which factors each tree's generalized mass with a tree-sparse dense factorization on one warp instead of articulated-body recurrences; trees beyond 64 DOFs keep the articulated-body path. Trees whose contacts touch only static or kinematic geometry run each substep in two fused kernels, about twice the throughput of the articulated-body path on Unitree G1 fleets. `reduced_backend="auto"`, the default, selects the dense backend where that fused substep can run every tree and the articulated-body path otherwise.
